# Skills opcionales

| Skill | Aplicación en el proyecto |
| --- | --- |
| `sites:sites` | Publicar, actualizar o verificar la presentación en ChatGPT Sites. |
| `pdf:pdf` | Leer y verificar PDFs del material de clase, diagnóstico o propuesta comercial. |
| `documents:documents` | Revisar o editar documentos DOCX usados como fuentes o entregables. |
| `presentations:Presentations` | Crear una versión alternativa en PPTX si el usuario la solicita. |
| `imagegen` | Crear recursos gráficos originales cuando aporten a la presentación. |

No se adoptan por ahora skills opcionales compartidas de `romex-agent-tools`, porque el repositorio de referencia no está disponible localmente. Este catálogo se actualizará si se proporciona esa fuente.
